Final Title
"The Cost of Mixing Models: No-Regret Exploitability in Heterogeneous LLM Agent Populations"

The Core Question
Does the classical theoretical prediction that no-regret learners are exploitable (Deng-Schneider-Sivan) actually hold when you test it empirically on real, heterogeneous LLM agent populations — i.e., can a stronger model exploit a weaker one for above-equilibrium payoff, measured via the regret metric? This has been proven in auction/abstract game theory but never tested on actual LLM agents.

Why This Title Won (vs. the reasoning-models/test-time-compute alternative)

"When Agents Lie" (July 2026) is the closest neighbor, but it measures deception/commitment-breaking, not regret/exploitability — a clean, defensible differentiation.

Step 9 — Add the τ (Reasoning Depth) Calculator
Now let's compute the second metric on this same data. Since TQRE is designed for single-shot games with a distribution over many trials (30 independent trials per game, per the Behavioral GT paper), and we only have one repeated-game run, we need to adapt it slightly: we'll treat each round's action as one "trial" against that round's specific context, giving us a rough per-model τ estimate across the whole game. This is a simplification we should note honestly in the final write-up, but it's the right starting point.

from scipy.optimize import minimize_scalar

def fit_tau(action_sequence, opponent_action_sequence, payoff_matrix, gamma=1.0, max_k=10):
    """
    Simplified TQRE fit: given a sequence of (your_action, opponent_action) pairs,
    find the tau (avg reasoning depth) that best explains the choices, assuming
    opponent strategy at each level is uniform random (level-0 baseline).
    """
    actions = ["C", "D"]

    def poisson_weight(k, tau):
        return (tau**k) * np.exp(-tau) / np.math.factorial(k)

    def level_k_strategy(k, payoff_matrix, prev_levels):
        if k == 0:
            return {"C": 0.5, "D": 0.5}
        expected_utils = {}
        for a in actions:
            eu = sum(prev_levels[k-1][opp_a] * payoff_matrix[(a, opp_a)][0] for opp_a in actions)
            expected_utils[a] = eu
        max_u = max(expected_utils.values())
        exp_vals = {a: np.exp(gamma * k * (expected_utils[a] - max_u)) for a in actions}
        total = sum(exp_vals.values())
        return {a: exp_vals[a] / total for a in actions}

    def neg_log_likelihood(tau):
        levels = {0: {"C": 0.5, "D": 0.5}}
        for k in range(1, max_k):
            levels[k] = level_k_strategy(k, payoff_matrix, levels)

        total_ll = 0
        for your_a, opp_a in zip(action_sequence, opponent_action_sequence):
            p_action = 0.0
            for k in range(max_k):
                p_action += poisson_weight(k, tau) * levels[k][your_a]
            p_action = max(p_action, 1e-10)
            total_ll += np.log(p_action)
        return -total_ll

    result = minimize_scalar(neg_log_likelihood, bounds=(0.01, 8.0), method='bounded')
    return result.x
